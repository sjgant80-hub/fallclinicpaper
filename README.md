# ◊ FallClinicPaper

**Sovereign UK healthcare clinic document generation.** Referral letters, discharge summaries, FP10 prescriptions, fit notes (Med3), consent forms, DNAR/ReSPECT, MCCD, medical reports. Single HTML file. Data never leaves the device. Prime 937.

Part of the **clinic bundle**: [fallclinic](https://github.com/sjgant80-hub/fallclinic) (919) · [fallcliniconboard](https://github.com/sjgant80-hub/fallcliniconboard) (929) · **fallclinicpaper** (937) · [fallclinicpractice](https://github.com/sjgant80-hub/fallclinicpractice) (941).

## For the end user

Generate, preview, and issue UK clinical documents from 10 templates. Locked regulatory clauses preserve statutory and GMC-mandated wording. Editable sections are the clinician's responsibility.

### Templates

| Code | Template | Category |
|---|---|---|
| REF-01 | Referral Letter | Clinical |
| CL-01 | Clinic Letter | Clinical |
| DS-01 | Discharge Summary | Clinical |
| RX-01 | Prescription (FP10) | Prescribing |
| MED3-01 | Fit Note (Med3) | Occupational |
| CON-01 | Consent Form | Consent |
| DNAR-01 | DNAR / ReSPECT | End of life |
| MCCD-01 | Medical Certificate of Cause of Death | End of life |
| SN-01 | Private Sick Note | Occupational |
| MR-01 | Medical Report (AMRA 1988) | Occupational |

### Key rules

- **Montgomery [2015]**: duty to disclose material risks for consent
- **Human Medicines Regulations 2012**: prescription requirements
- **MCA 2005**: capacity assessment for DNAR/consent
- **NICE NG12**: 2WW urgent cancer referrals
- **Births and Deaths Registration Act 1953**: MCCD requirements
